## 💎 Обзор проекта
**BookStore Premium** — это высокотехнологичная платформа для автоматизации книжного ритейла, разработанная как полноценная ERP/POS система. Проект демонстрирует современные подходы к проектированию реляционных баз данных и созданию отзывчивых веб-интерфейсов.

---

## 🚀 Ключевые особенности v2.0
- **Modern Enterprise UI**: Стекляный интерфейс (Glassmorphism), анимации на CSS3 и типографика Inter.
- **Интеллектуальный дашборд**: Сводные данные по продажам, запасам и последним операциям.
- **Гибкие прайс-листы**: Поддержка динамического ценообразования с привязкой к датам и категориям.
- **Система маркетинга**: Механизм акций и автоматических скидок.
- **RBAC (Role Based Access)**: Ограничение функционала для ролей `admin`, `manager`, `cashier`.
- **Печать чеков**: Генерация профессиональных торговых чеков (80мм термопечать).

## 🏗 Структура проекта
```text
├── app/                  # Backend-логика (Node.js/Express)
│   ├── config/           # Конфигурация БД (Sequelize)
│   ├── controllers/      # Контроллеры обработки бизнес-логики
│   ├── middleware/       # RBAC и проверка авторизации
│   ├── models/           # Схемы таблиц PostgreSQL (Models)
│   └── routes/           # Определение REST-эндпоинтов
├── public/               # Frontend-ресурсы
│   ├── app.js            # Основная логика интерфейса и POS
│   ├── reports.js        # Аналитический модуль и RBAC
│   ├── style.css         # Современный дизайн и print-стили
│   └── index.html        # Single Page Application структура
├── server.js             # Точка входа в backend-сервер
├── docker-compose.yml    # Инфраструктура (Node + Postgres + pgAdmin)

```

## 📊 Модель данных и API
### Основные эндпоинты:
| Группа | Маршруты | Описание |
| :--- | :--- | :--- |
| **Товары** | `/api/products` | Управление каталогом книг и канцелярии |
| **Цены** | `/api/pricelists` | Формирование и привязка цен к периодам |
| **Продажи** | `/api/sales` | Регистрация транзакций и продажа товаров |
| **Категории** | `/api/goodsgroups` | Управление иерархией товаров |
| **Акции** | `/api/promotions` | Создание и управление скидками |
| **Пользователи** | `/api/users` | Управление персоналом и авторизация |

## ⚙️ Автоматизация и бизнес-логика
- **Транзакции**: Все продажи проводятся через транзакции Sequelize для обеспечения целостности данных.
- **Пересчет склада**: При совершении продажи количество товара на складе уменьшается автоматически.
- **Безопасность**: Пароли пользователей хэшируются с использованием `bcryptjs` через Sequelize Hooks.
- **Валидация**: Серверная проверка обязательных полей и типов данных.

## 📥 Установка и запуск

1. **Запуск через Docker (самый быстрый способ)**:
```bash
docker-compose up --build
```
*Docker автоматически создаст базу, применит миграции и запустит сервер на порту 6868.*

2. **Настройка без Docker**:
- Создайте БД в PostgreSQL.
- Настройте `.env` (см. `.env.sample`).
- Выполните `npm install` и `node server.js`.
